# My Personal Website

## Project Overview

This project is a personal website created using HTML and CSS. The website includes three pages: Home, Projects, and About Me.

The purpose of this project is to share information about my interests, education, experience, and career goals while demonstrating accessible and responsive web design.

## Website Pages

- **Home (index.html):** Introduces me and provides an overview of my interests and goals.
- **Projects (projects.html):** Displays projects and areas of interest.
- **About Me (about.html):** Shares information about my background and includes a contact form.

## Technologies Used

- HTML5
- CSS3
- Visual Studio Code
- GitHub Pages

## Accessibility Improvements

The website includes several accessibility features:

- Semantic HTML elements such as header, nav, main, section, and footer.
- Descriptive page titles and meta descriptions.
- A skip-to-main-content link for keyboard users.
- Descriptive alternative text for meaningful images.
- Clear labels for contact form fields.
- Required form fields to help users provide complete information.
- Visible keyboard focus indicators.
- Readable text and consistent color choices.
- Responsive layouts for different screen sizes.
- Reduced-motion support for visitors who prefer less animation.

## Visual Design and Gestalt Principles

The website uses Gestalt design principles to create a clear and organized layout.

### Proximity

Related information is grouped together in sections and cards. This helps visitors understand which information belongs together.

### Similarity

Consistent colors, fonts, headings, buttons, and navigation styles are used across all three pages. This creates a unified appearance and makes the website easier to navigate.

### Color Palette

The website uses the following colors:

| Color | Hex Code | Purpose |
|---|---|---|
| Teal | #264653 | Headers, navigation, and buttons |
| Cream | #f4f1de | Page background |
| Orange | #f4a261 | Highlights and visual accents |
| White | #ffffff | Content backgrounds |

## Contact Form

The About Me page includes a contact form with fields for a visitor's name, email address, and message.

The fields have visible labels and required-field validation. The form uses a mailto action, so visitors need a compatible email application configured to submit a message.
